# StarMind LOGO 素材包

本素材按此前 StarMind 原型的“深绿色圆角方形底 + 浅绿色四芒星”样式重建。
此前原型源文件未检索到，因此这是一套供本次重构版使用的重建素材，并非从原始文件精确提取的正式品牌资产。

## 设计参数

- 应用名称：StarMind（注意大小写）
- 产品描述：AI 团队工作台
- 底色：#123D32
- 星形颜色：#C8F59B
- SVG 画板：1024 × 1024，圆角半径 224
- 图标外部圆角区域透明，PNG 和 ICO 均保留透明通道

## 给本地 agent 的接入说明

1. 使用 starmind-logo.svg 作为统一图标源文件。
2. 安装包、桌面快捷方式、应用 EXE 图标使用 starmind-app.ico。
   该 ICO 内含 16、24、32、48、64、128、256 像素图层。
3. 应用窗口与网页 UI 按需要使用 SVG 或对应尺寸 PNG。
4. 托盘浅色背景使用 starmind-tray-on-light-*；深色背景使用 starmind-tray-on-dark-*。
   tray 文件是透明背景的单色四芒星，适配系统主题时选择对应版本。
5. 将 DeepSeek Harness Desktop 的用户可见产品名称、产品描述及产品图标统一替换为 StarMind。
6. 构建后在 Windows 上检查安装器、桌面快捷方式、任务栏、窗口和托盘图标是否正确。
   这些素材已完成格式检查；最终系统主题、DPI 和打包接入效果仍需在实际应用中检查。

本文件包不包含安装包。网关首次启动引导与 Setup 打包仍由本地 agent 继续完成。
