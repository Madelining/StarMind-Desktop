# 对话记录

本目录保存与 StarMind 讨论方案时的会话记录，用于复盘「结论是怎么来的」，而不是只看最终文档。

| 文件 | 内容 | 规模 |
|---|---|---|
| `2026-11-01-ADT-CPD-方案讨论.md` | 从「自动化任务是什么」到「上下文是否入库」的完整对话稿：9 轮提问、9 段回答、157 次工具调用 | 约 215 KB / 4943 行 |
| `raw/main-session-157fbed1.jsonl.zstd` | **主会话原始存档**（多帧 zstd），事件级保真副本 | 约 1.1 MB |
| `raw/subagent-archify-a0189c95.jsonl.zstd` | 架构图子 agent 的原始存档（生成 `docs/architecture/` 的那次委派） | 约 0.8 MB |

## 两种粒度，用途不同

- **`.md` 稿**：给人读。用户提问与助手回答是**全文**；工具调用保留入参与结果摘要（单条上限 1200 / 1500 字符），过长则截断并标注原文总字数。
- **`raw/*.zstd`**：给机器读。完整事件流，**不截断**——包含每一次工具调用的完整入参和完整输出、每个 turn/step 边界、模型选择与权限变更事件。需要精确复现某一轮到底看了什么、跑了什么时看这个。

## 记录了什么

- 用户的每一轮提问原文
- 助手的每一段回答原文
- 工具调用（`grep` / `pwsh` / `write` / `present` / `skill` / 子 agent 等）及其结果
- 交付物登记（`present` 调用的文件路径）

## 没有记录什么

- **推理过程（reasoning）**：模型内部思考链不入存档。
- 图片类工具的实际输出内容（只保留调用记录与结构化证据）。
- 会话开始前的系统上下文（技能目录、运行期记忆快照、AGENTS.md 注入）。

## 怎么再导出一份

会话存档位于 `<DSH_HOME>/sessions/<workspace>/<session-id>/session.v4.jsonl.zstd`。
这个文件是**多帧 zstd 串联**格式（每追加一条记录就追加一个帧），Node 自带的 `zstdDecompressSync` 只解第一帧就返回，所以脚本按帧魔数 `0x28 B5 2F FD` 切分后逐帧解压：

```bash
node scripts/export-session.mjs <session.v4.jsonl.zstd 路径> <输出.md 路径>
```

脚本会把事件流渲染成 Markdown（用户 / 助手 / 工具调用 / 工具结果），并统计轮次。
